# 除了自身以外数组的乘积

## 思路

对于每个位置 `i`：

`res[i] = 左边所有元素的乘积 × 右边所有元素的乘积`

如果每次都重新计算左右两边，时间复杂度会达到 `O(n²)`。

可以用两次遍历优化：

1. **从左往右遍历**
   - 用 `left_mul` 记录当前位置左边所有元素的乘积。
   - 先令 `res[i] = left_mul`，再更新 `left_mul *= nums[i]`。

2. **从右往左遍历**
   - 用 `right_mul` 记录当前位置右边所有元素的乘积。
   - 令 `res[i] *= right_mul`，再更新 `right_mul *= nums[i]`。

这样每个元素只被处理两次。

## 复杂度

- 时间复杂度：`O(n)`
- 额外空间复杂度：`O(1)`（不考虑返回数组）

## 记忆

> 除了自己以外的乘积 = 左边乘积 × 右边乘积  
> 前缀扫一遍 + 后缀扫一遍

## 注意点
有两个注意点：一个是我扫两边可以让我的时间复杂度优化到O(N)，另一个是我倒着扫的范围必须是range(n-1,-1,-1)。
