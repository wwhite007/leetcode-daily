## 方法2：三次反转

### 思路

假设：

```text
nums = [1,2,3,4,5,6,7]
k = 3
```

我们希望将数组向右轮转 `3` 位：

```text
[1,2,3,4,5,6,7]
        ↓
[5,6,7,1,2,3,4]
```

可以把最终结果看成两个部分：

```text
[5,6,7] + [1,2,3,4]
```

也就是说，我们实际上只是希望：

```text
[1,2,3,4] + [5,6,7]
```

变成：

```text
[5,6,7] + [1,2,3,4]
```

可以通过 **三次反转** 实现。

---

### 第一步：反转整个数组

原数组：

```text
[1,2,3,4,5,6,7]
```

反转后：

```text
[7,6,5,4,3,2,1]
```

此时可以看成：

```text
[7,6,5] + [4,3,2,1]
```

虽然两个子数组的位置已经交换了，但它们各自内部的顺序也被反转了。

---

### 第二步：反转前 `k` 个元素

将：

```text
[7,6,5]
```

反转为：

```text
[5,6,7]
```

于是数组变成：

```text
[5,6,7,4,3,2,1]
```

---

### 第三步：反转后 `n-k` 个元素

将：

```text
[4,3,2,1]
```

反转为：

```text
[1,2,3,4]
```

最终得到：

```text
[5,6,7,1,2,3,4]
```

---

### 核心记忆

可以记成：

```text
原数组：

A + B

第一次整体反转：

reverse(B) + reverse(A)

再分别反转两个部分：

B + A
```

也就是利用：

> **负负得正：一个子数组反转两次，内部顺序恢复不变，但两个子数组的位置发生交换。**

---

### Python 实现

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:

        n = len(nums)
        k = k % n

        # 1. 反转整个数组
        nums.reverse()

        # 2. 反转前 k 个元素
        nums[:k] = reversed(nums[:k])

        # 3. 反转后 n-k 个元素
        nums[k:] = reversed(nums[k:])
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`（思想上为原地反转）
