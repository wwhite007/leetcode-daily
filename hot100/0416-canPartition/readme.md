# 前缀后缀思想转向0/1背包
0/1 背包的本质：

对每个物品只有选和不选两种选择，并且每个物品最多使用一次。

dp[j]：
使用已经遍历过的物品，能否或最优地达到容量 j。

状态转移：
当前结果 = 不选当前物品的结果 + 选择当前物品的结果。

布尔型：
dp[j] = dp[j] or dp[j-num]

最大值型：
dp[j] = max(dp[j], dp[j-weight] + value)

方案数型：
dp[j] += dp[j-num]

初始化：
dp[0] 是所有转移的起点。

循环顺序：
先遍历物品，再倒序遍历容量。

倒序原因：
避免当前物品在同一轮更新中被重复使用。

口诀：
一个物品只能用一次，容量从大到小遍历。
