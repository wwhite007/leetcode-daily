# 和为K的子序列
# 基本思路
在我的思路1，我先求出前序和，子序列的和等于两个前序和的插值，但问题是构造字典的时候我必须储存不同位置的index而不能单纯储存数量,<br>
否则可能导致前减去后，这样是负数了。
# 改良1
在我的解法2，我对解法1做出了调整，具体还是利用了count_sum这个字典实时更新的属性，<br>
每一次更新前对于后减前进行统计然后再更新，这样子可以完全压缩到O(N).
# 改良2
在我的思路3，我这里甚至不需要array来储存我的前序和，每一次只需要储存在一个数字里面就完全ok。<br>
然后针对我这个前序和直接等于k的情况，我直接设置字典为{0:1}就可以不需要分类讨论<br>
最后战绩：时间复杂度超越98%
